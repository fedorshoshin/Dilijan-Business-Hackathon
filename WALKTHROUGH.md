# Walkthrough — the three roles, start to finish

The checklist for Phase 7 (tasks 7.2 and 7.5). Run it on **real phones**, with the
app installed to the home screen, not in a browser tab. Ideally three phones
(one per person) and at least one iPhone and one Android among them.

Last run in full on 2026-10-08, in a phone-sized browser against the live
server: every step below passed. What has **not** been done yet is the same run
on real phones — that is what this list is for.

## Before you start

1. On each phone, open the site and follow "Put it on your home screen".
2. Open the app **from the home-screen icon**. It should open full screen, with
   no address bar, and be called Cleaner Armenia.
3. Sign up one account per phone: a **reporter**, a **cleaner**, a **donor**.
   Tick the matching role on the sign-up form.

No real money moves: giving is simulated, and says so on the screen.

## 1. Reporter — report a spot

| Step | What should happen |
| --- | --- |
| Report tab → **Report a spot** | The form opens with a map |
| Tap **Use my current location** | The pin lands where you are |
| Fill in the place, a short name, a description | — |
| **Take a photo** | The camera opens; the photo appears in the form |
| Pick how bad it is and how long it takes | The suggested price changes with the time |
| Type your own price | Your number stays when you change the time again |
| **Post this report** | You land on the spot's page; the photo uploads |
| **Edit this report** → change the title or price → **Save changes** | The page shows the new values |

## 2. Donor — fund it

| Step | What should happen |
| --- | --- |
| Map tab → tap the reporter's new spot → **Fund this cleanup** | "Giving to this spot" with its name |
| Pick an amount → **Give** | "Thank you" and you land on **Your impact** |
| Your impact | The gift is listed "For" that spot, not yet spent |
| Give tab → give to the general pot | "In the pot now" rises by that amount |

## 3. Cleaner — take it, clean it

| Step | What should happen |
| --- | --- |
| Jobs tab | The new spot is on the board, with what it pays |
| Open it → **Take this on** | "Yours"; it leaves everyone else's board |
| On the **reporter's** phone, open the Map tab again | The spot shows "Crew on it" |
| Under **After**, take a photo of the cleaned spot | The photo uploads |
| **I have cleaned it** | "Waiting for the reporter to check" |

## 4. Reporter — confirm and pay

| Step | What should happen |
| --- | --- |
| Report tab | A number badge on the tab: one spot to check |
| Open the spot | Before and after photos side by side |
| Tap **5** → **Confirm and pay** | "Confirmed. … has been paid" |
| *(Optional, on another spot)* tap **1** → **Send it back** | It returns to the cleaner, nobody is paid |

## 5. Everyone — check the money

| Phone | What should happen |
| --- | --- |
| Cleaner: Jobs → **Your work** | "Earned so far" includes the price; the job says "… paid" |
| Donor: Give → **Your impact** | The gift names the cleanup, with before/after photos, date, cleaner and rating; given = spent + not yet spent |

## 6. Two checks only real phones can do

- **No signal.** Turn on airplane mode, take a photo for a spot, turn signal back
  on. The photo should upload by itself.
- **Video.** From the reporter's phone, add a short video to a spot. It should
  play on the other phones, including an iPhone.

## When something goes wrong

Write down which phone (iPhone or Android, which browser), which step, and what
you saw instead. A screenshot helps most.
